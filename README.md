🎯 Project Overview
Getting Started with React + Vite
This project is bootstrapped with Vite - a next-generation frontend tooling.

Available Scripts
In the project directory, you can run:

npm run dev
Runs the app in development mode.
Open https://amrutamapp.vercel.app/ to view it in your browser.

The page will reload when you make changes.
You may also see any lint errors in the console.

npm run build
Builds the app for production to the dist folder.
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.
Your app is ready to be deployed!

npm run preview
Locally preview the production build.

Learn More
You can learn more in the Vite documentation.

To learn React, check out the React documentation.

Key Features
Fast Refresh: Instant feedback on changes

Optimized Builds: Production-ready optimizations

Type Safety: Full TypeScript support

Modern Tooling: Latest development tools

Performance: Built-in code splitting and optimization
